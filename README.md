# Qari Sadiq Naeem — Online Quran Academy

Premium Islamic-themed Next.js website for Qari Sadiq Naeem.

## Included
- Responsive premium landing page
- Courses: Noorani Qaida, Nazra Quran, Hifz-ul-Quran, Tajweed, Quran Translation, Tafseer, Masnoon Duas, Islamic Studies
- About/experience section
- 17 years teaching experience
- 11 years Pakistan + 6 years Sharjah, UAE home tuition experience
- Kids & adults section
- International students section
- How it works
- FAQ accordion
- Admission form UI
- Mobile navigation
- SEO metadata
- No external image dependency; hero artwork is CSS-based

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Important before production
The admission form currently demonstrates the UI and client-side success state. Connect it to your preferred backend/database/email/WhatsApp workflow before launch.

Also replace any generic course/teaching claims with the exact wording approved by Qari Sadiq Naeem, and add his real professional photo/certificates if available.

## Recommended production stack
Next.js + PostgreSQL/Supabase + server-side form validation + email/WhatsApp notification.

Built with Next.js App Router.
